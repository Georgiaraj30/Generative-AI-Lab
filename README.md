# Generative AI Lab

**MSc Data Science – Practical Exercises**

## About the Project
This repository contains 12 practical exercises completed as part of the Generative AI Lab. The exercises explore generative AI models, computer vision, large language models, multimodal AI, and AI-powered applications using Python and Google Colab.

## List of Experiments

1. Text to Image Generation using Diffusion Models
2. Face Mask Detection using Pre-trained Models
3. Object Detection in Images using YOLOv5
4. Image Caption Generation
5. Multimodal AI Assistant using Gemini
6. Text Summarization System using BART
7. Recipe Generator using LLM-Based Prompt Engineering
8. Code Generator
9. AI Quiz Generator
10. Web Page Summarization
11. Placement Brochure AI – Case Study 1
12. AI Airways Assistant – Case Study 2

## Tools and Technologies
- Python
- Google Colab
- Generative AI Models
- Hugging Face Transformers
- TensorFlow and other relevant libraries

## Purpose
To gain practical experience in implementing Generative AI techniques and developing AI-powered applications.
